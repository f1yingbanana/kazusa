# Vigilante Crew Room

The Vigilante Crew isn't an official club, so it has no proper room; it uses an
old ground-floor storeroom nobody else wanted. A street map of Trinity covered
in coloured pins hangs on the wall, one pin for every incident, and a kettle and
a tin of biscuits sit on a crate.

Patrol routes for the evening are written up on the door each afternoon.
