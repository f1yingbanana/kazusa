# Gehenna Class 2-D

A third-floor classroom whose roll is a who's-who of trouble: council members
who skip, delinquents with bounties, and the officers sworn to arrest them, all
assigned to the same rows. Attendance is a contest of nerve; a seat by the
window has a good view of the main gate.
